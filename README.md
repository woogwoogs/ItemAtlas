# ItemAtlas

PoE2 base and modifier reference. Patch 0.5.5; snapshot September 8, 2026.

## Controls

* Hover an inventory or stash item and press **F8** for base tables or **F9** for modifiers. Both hotkeys are configurable.
* Bases remain separated into regular and Runeforged/Runemastered sections, with defence-type filters. Implicits are visible and wrapped beside each base name.
* Select a base to browse its uniques and modifier pool. 



## Base data

Base values are at zero quality, before item rolls and build modifiers. Raw DPS uses average base damage and attack time, including elemental base damage but excluding implicit effects. Drop level is not item level or an equipment requirement. Restricted/legacy records are hidden by default except the selected base.
